# Booki

Intégration de la page d'accueil de Booki, une agence de voyage fictive.
Projet 2 du parcours Développeur web — OpenClassrooms.

## Technologies
HTML5, CSS3 (Flexbox), Font Awesome, Google Fonts (Raleway).
Aucun framework ni préprocesseur.

## Fonctionnalités
Intégration desktop-first, responsive aux points de rupture 1024 px et 768 px.
Code valide aux validateurs W3C HTML et CSS.

## Ouvrir le projet
Cloner le dépôt et ouvrir `index.html` dans un navigateur.
